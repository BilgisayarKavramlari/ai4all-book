# Lab 2.1 — Train a Classifier

| Field | Value |
|---|---|
| Type | Build |
| Objectives | O2 (LO1) · tags AI4K12:3, UNESCO:TECH-U |
| Time | 25 minutes, at home or in Compass (optional, recommended) |
| Materials | A free, browser-based, no-code image-classifier tool; a phone or laptop camera; three everyday objects that are easy to confuse (for example a pen, a pencil and a marker) |

## Steps (tool-neutral)
1. Choose three everyday objects that are easy to confuse.
2. Take about 30 photos of each, from different angles, on the same background.
3. Train a three-class model in the tool. Note how many examples each class has.
4. Test it on 10 **new** photos per object that you did not use in training. Record how many it gets right for each class.
5. Write two sentences: what did the model seem to learn, and where did it go wrong?

[COMPASS: ch02-lab1 — current tool steps and screenshots]

## Expected observations
Most new photos are classified correctly when the background and lighting match training. Errors cluster on the two most similar objects and on unusual angles. Keep the test photos: Lab 2.2 reuses them.

## Debrief (3–5)
1. Which object was hardest, and why might that be? (explain)
2. Did the model learn the object or something else in the photo? How could you tell? (analyze)
3. Where in the learning loop (predict, measure, adjust, repeat) did the tool hide the details from you? (explain)

## Deliverable and rubric
Ungraded. A short observation note (counts per class plus two sentences). Useful material for A2 (terms: training data, label, model, test set).

## Accessibility and alternatives
Paper version on the course site: printed object cards sorted first by rules the student writes, then by "examples" from a provided training pile; compare. Screen-reader route: a provided tabular dataset in an accessible spreadsheet with a pre-computed results table.

## Safety and privacy
Photograph objects only: no people, no faces, no documents, no screens showing personal data. Check whether the tool uploads photos (see Lab 2.3).

## Instructor notes
Remind students that test photos must not be reused from training. If a tool requires an account, students may use the paper version instead.
