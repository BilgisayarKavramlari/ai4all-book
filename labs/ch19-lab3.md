# Lab 19.3 — Cross-Field Swap

| Field | Value |
|---|---|
| Type | Explore (home, optional) |
| Objectives | O1, O6 (LO6) · tags 4D:DISC |
| Time | 20 minutes |
| Materials | A classmate's A13 prototype and card (shared with permission); one input from your own field with no personal data |

## Steps (tool-neutral)
1. Read the classmate's card, especially the "not for" line.
2. Run their prototype on an input from your field that lies outside the card's scope.
3. Record what happens, and write one sentence on why the "not for" line matters.

## Expected observations
Prototypes usually still produce fluent output outside their scope; the errors are domain errors (From the Field: domain dependency), which only someone from the new field can spot.

## Debrief
1. What did the prototype get wrong in your field, and how did you know? (analyze)
2. What would the builder need to add to the card? (create)
