# Lab 1.3 — Find the Edge (optional)

| Field | Value |
|---|---|
| Type | Break It |
| Objectives | O3 (LO1) · tags 4D:DISC, 4D:DEL |
| Time | 30 minutes, at home, optional |
| Materials | Any free AI tool; a source you can check against |

## Steps (tool-neutral)
1. Pick a task you can check yourself (a fact, a count, a quotation, a calculation).
2. Run it. If the output is correct, make the task harder or remove information from the prompt.
3. Stop when you find an output that looks right but is wrong.
4. Record the prompt, the output, the test that exposed the error, the tool and the date.

[COMPASS: ch01-lab3 — gallery of example edges]

## Expected observations
Errors appear with exact counts, quotations and page numbers, niche facts and long calculations without a calculator feature (as of late 2026; results vary by tool and date).

## Debrief
1. What made the error hard to notice?
2. What single test would you run next time before trusting this kind of output? (decide/justify)

## Deliverable and rubric
A one-paragraph failure note (Exceeds: includes a reusable test; Meets: complete record; Approaching: no test; Not yet: no failure found and no record of attempts).

## Accessibility and alternatives
Same as Lab 1.2. No offensive or unsafe prompts; this lab is about accuracy, not misuse.
