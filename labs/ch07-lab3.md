# Lab 7.3 — Answer Mode Versus Tutor Mode

| Field | Value |
|---|---|
| Type | Compare |
| Objectives | O3, O4 (LO4) · tags 4D:DEL, 4D:DESC, 4D:DISC |
| Time | 15 minutes, at home or in Compass (optional) |
| Materials | An AI chat tool (university-provided by default) that can open a fresh, temporary chat; one question from a course you are taking, with an answer you can check |

## Steps (tool-neutral)
1. **Answer mode:** in a fresh chat, ask the question directly.
2. **Tutor mode:** in another fresh chat, paste your tutor-mode setup (section 7.5) and work through the same question.
3. For each chat, count how many times *you* recalled or produced something (an attempt, an explanation, a prediction).
4. Close both chats and answer one closed-book question on the same topic. Score it against your course source.

[COMPASS: ch07-lab3]

## Expected observations
Answer mode is faster and usually involves no recall by you. Tutor mode takes longer, and the closed-book question tends to feel harder to dodge. Some tools give the answer in tutor mode anyway; note when.

## Debrief (3–5)
1. In which chat did you recall or produce more? (analyze)
2. Which turns would you code S, and which C? (analyze)
3. When would answer mode be the right choice for you? (evaluate)
