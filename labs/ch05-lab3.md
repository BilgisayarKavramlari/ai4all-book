# Lab 5.3 — Test a "Magic" Phrase

| Field | Value |
|---|---|
| Type | Break It |
| Objectives | O4, O5 (LO2) · tags 4D:DISC, 4D:DESC |
| Time | 40 minutes, at home or in Compass (optional) |
| Materials | Any AI chat tool; a short task with three checkable criteria; two test inputs; the scoring sheet (eLearning) |

## Steps (tool-neutral)
1. Choose one popular prompting "trick", a phrase some people believe always improves answers: a politeness phrase, an expert role, an offered tip, or a phrase you have seen recommended online.
2. Write a short task, three checkable criteria and two test inputs (a typical one and a different one).
3. Run the prompt **with** the trick three times and **without** it three times, on each input, each run in a fresh, temporary chat (12 runs in all).
4. Score every output against the three criteria. Count how many runs met all three in each condition.
5. Write a conclusion limited to your test: task, tool, date, number of runs.
6. If the trick made an output worse in a way you did not expect, **save this for your Failure Diary (Chapter 4).**

[COMPASS: ch05-lab3 — a scoring sheet]

## Expected observations
Small differences in either direction are common and often disappear with more runs, as in Meincke et al. (2025a); occasionally one input changes noticeably. Three runs per condition cannot show a small effect, which is part of the lesson; pooled class results show more.

## Debrief (3–5)
1. Would you now recommend the trick to a classmate? What would you need to see first? (evaluate)
2. Did the two inputs agree? What does disagreement tell you? (analyze)
3. How many runs would you need before trusting a difference? (evaluate)

## Deliverable and rubric
Ungraded. A scored table and a two-sentence conclusion.

## Accessibility and alternatives
No-device route: score the dated sample outputs on eLearning (both conditions, both inputs; model and date given).

## Safety and privacy
No personal data; do not test phrases that ask the tool to bypass its safety rules.

## Instructor notes
Pool class totals in week 4 (a shared sheet by trick and input); pooled runs make the "small and inconsistent" pattern visible. Needs the dated sample outputs (instructor package).
