# Lab 3.3 — Same Prompt, Five Answers

| Field | Value |
|---|---|
| Type | Explore |
| Objectives | O1 (LO1) · tags UNESCO:TECH-U, 4D:DISC |
| Time | 15 minutes, at home or in Compass (optional) |
| Materials | Any chat tool; a notes page |

## Steps (tool-neutral)
1. Use the two prompts you wrote for the section 3.2 Your Turn, or write one prompt with one correct answer (for example, a date or a definition from your field) and one with many good answers (for example, a name for a study group or a slogan).
2. Run each prompt five times, each in a new chat. Copy the answers with the tool name and date.
3. For each prompt, mark what stays the same and what changes.

[COMPASS: ch03-lab3 — how to start a new chat or temporary chat in current tools]

## Expected observations (instructor notes)
The open prompt varies far more than the prompt with one answer. Even the one-answer prompt may vary in wording, length and extra details, and occasionally in the answer itself.

## Debrief (3–5)
1. Which prompt varied more, and why? Use the four steps in section 3.2. (explain)
2. If one of the five answers to the one-answer prompt was wrong, what does that tell you about trusting a single run? (evaluate)
3. When is variation useful in your work, and when is it a risk? (analyze)

## Deliverable and rubric
Ungraded. The ten answers and a three-sentence comparison.

## Accessibility and alternatives
Dated sample outputs on the course site for students who prefer not to use AI tools. Paper version: roll dice to pick tokens from a printed score table based on section 3.2.

## Safety and privacy
No personal or confidential information in prompts.
