# Lab 12.3 — Re-test an Old Fit

| Field | Value |
|---|---|
| Type | Explore (home, optional) |
| Objectives | O1, O6 (LO2) · tags 4D:DISC, 4D:DIL |
| Time | About 20 minutes |
| Materials | Your Chapter 5 A3 iteration log: the final prompt, its success criteria and its test inputs (typical, different, edge), with the tool and date you used |

## Steps (tool-neutral)
1. Open the same tool you used for A3. Record the model if shown and today's date.
2. Rerun your final prompt on each test input twice, in fresh chats with memory and standing instructions off, word for word.
3. Score each output against your A3 criteria. Compare with your A3 scores.
4. Decide: has a re-test trigger fired (a new model, changed options, changed terms)? Would your A3 verdict still hold?

In Compass (optional) and on your course site: where to find model and version information, by tool.

## Expected observations
Some prompts behave the same; others change in format, length or correctness, even when the tool's name has not changed (Chen, Zaharia & Zou, 2024, document this for 2023 models). A changed output is not proof that the model changed, because outputs vary from run to run; two runs per input help tell the difference.

## Debrief
1. What changed, and could ordinary run-to-run variation explain it? (analyze)
2. What would you keep in your own files so that a re-test takes minutes? (apply)

## Deliverable
Ungraded. A changed result can become an entry in your Failure Diary (Chapter 4).

## Accessibility and alternatives
If you no longer have access to the A3 tool, rerun the prompt in another tool and treat it as a two-tool comparison.
