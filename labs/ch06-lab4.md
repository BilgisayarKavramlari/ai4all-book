# Lab 6.4 — Audit Your Standing Context

| Field | Value |
|---|---|
| Type | Audit |
| Objectives | O4 (LO2) · tags 4D:DIL, 4D:DESC |
| Time | 15 minutes (10-minute version: memory or saved notes only), at home or in Compass (optional) |
| Materials | An AI tool you use that has standing instructions, project spaces or memory, or the provided sample memory list (course site); the audit sheet |

## Steps (tool-neutral)
1. **Find the layers (3 min).** Open your tool's standing instructions (in its options), project files and memory list (Compass shows where for current tools). If your tool has none of these, use the provided sample memory list.
2. **Ask four questions of each item (7 min).** Is it still true? Is it still needed? Would I be comfortable if a classmate read it? Does it belong in every chat, in one project, or only in one conversation?
3. **Act (3 min).** Fix, move or delete at least one item. **Check before you delete:** in some tools, deleted notes or chats cannot be restored. If your tool draws on past chats instead of a list of notes, you cannot review it item by item: record whether that option is on, and what you changed.
4. **Record (2 min).** On the audit sheet, record **only the item types and the action taken**, for example "memory note about a past job: deleted, outdated" or "standing instruction about tone: moved to one project." **Never record or submit the contents.**

## Expected observations
Most students find at least one stale or forgotten item, often a memory note created in passing or a standing instruction written for one task. Some find personal details they did not mean to store.

## If it does not work
If your tool stores nothing, record "no persistent context" and do the sample-list route as well.

## Debrief (3–5)
1. Which item surprised you most, by type? (analyze)
2. Which items did you move from "every chat" to one project, and why? (evaluate)
3. How often should you repeat this audit? (evaluate)

## Deliverable and rubric
The audit sheet (types and actions only). Ungraded.

## Accessibility and alternatives
The sample-list route needs no account. Screen-reader-friendly audit sheet (plain table).

## Safety and privacy
Do not share screenshots of memory lists or instructions. Record only types and actions. If you find another person's information stored, delete it. Chapter 15 covers what never to store.

## Instructor notes
Never collect contents. A short class tally of item types (for example, "stale facts about me", "instructions written for one task") is enough for discussion.
