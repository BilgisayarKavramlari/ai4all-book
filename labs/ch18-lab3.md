# Lab 18.3 — Find the Rule's Owner

| Field | Value |
|---|---|
| Type | Apply (optional, at home) |
| Objectives | O1 (LO5) · tags 4D:DIL |
| Time | 15 minutes |
| Materials | The Regulation Map (section 18.1; printable on eLearning); rules you can read yourself |

## Steps (tool-neutral)
1. Pick one AI use in your field, job or club (no personal data).
2. On a blank Regulation Map, list the rules that may apply in each layer you can find: law (EU, U.S. federal, state, city), terms and licenses, contracts, your organization's policy.
3. For each rule, name its owner by role (an office, a manager, a client, a regulator) and where its text is.
4. Mark which rule is strictest for this use.
5. Write the one question you would put to the owner of the strictest rule.

## Expected observations
The nearest layers (course, employer, client, tool terms) usually have readable texts and reachable owners; some rules are unwritten (note that: an unwritten rule has no text to cite).

## Debrief
1. Which rule would you cite as D evidence, and which only as "may apply"? (evaluate)

## Deliverable and rubric
Ungraded; feeds the optional Mini-Project (policy comparison note).

## Accessibility and alternatives
A text version of the map is on eLearning.

## Safety and privacy
Use only rules you can read yourself; no confidential policies from an employer without permission. Not legal advice.
