## Steps (tool-neutral)
1. **Fixed and changing parts (5 min).** Take your final prompt from assignment A3 (your Chapter 5 prompt and iteration log), or the provided sample. Underline what stays the same every time you would use it (task, audience, constraints, output format, any in-context examples) and circle what changes (the material).
2. **Write the template (5 min).** Replace each changing part with a placeholder in braces, such as {NOTES} or {DATE}. Put the material first and the full task last. Add a line "Do not use for: …".
3. **Write pass criteria (2 min).** Two or three criteria you can score met, partly met or not met. Reuse your A3 criteria if they still fit.
4. **Test (13 min).** In fresh chats, run the template on three test inputs it has not met before: a typical input, a different input and an edge input (Chapter 5's terms). Score each output against each criterion.
5. **Fix and version (5 min).** Make one change for one failure. Rerun all three inputs, not only the one that failed. Save the result as v1.1 with the date, the tool and model name, and one line on what changed. This is the first entry in your library. If nothing failed, make the edge input harder until something does, and record that.

**10-minute version:** steps 1–3 only.

## Expected observations
Most templates pass the typical input and fail at least one criterion on the edge input, often by adding material that is not in the input (an invented decision, a made-up number). The fix is usually a one-line instruction about what to do when something is missing. Some students find that a change for the edge input breaks the typical one; rerunning all inputs is how they notice.

## If it does not work
If every input passes on the first try, your edge input is not hard enough: choose an empty, very short or contradictory input. If the tool refuses or errors, record that as a result. If you cannot use a tool, use the alternative assignment's sample library and write a test plan instead of running tests.

## Debrief (3–5)
1. Which part of your A3 prompt was hardest to turn into a placeholder, and why? (analyze)
2. What did the edge input reveal that the typical input did not? (analyze)
3. Did your fix for one input change the result for another? (evaluate)
4. When should your template *not* be used? (evaluate)

## Deliverable and rubric
The first entry of the optional personal prompt library (Application Assignment, Chapter 6). Self-check against the library rubric (Task, Process: tests, Process: revision). Ungraded.

## Accessibility and alternatives
No-device or opt-out route: the alternative assignment (repair the provided sample library) without running a tool. A screen-reader-friendly version of the entry template (plain table) is on eLearning. Placeholders can be written in any consistent form; braces are only a convention.

## Safety and privacy
No personal or confidential data in templates or test inputs, yours or anyone else's; use constructed or public material. Do not store the template with real inputs inside it. Use a fresh, temporary chat so that earlier chats and memory do not shape the test (Chapter 6, section 6.5). Save outputs as text excerpts.

## Instructor notes
Students who finish the A3 sprint early can start steps 1–2 in class and test at home. Collect two or three anonymized edge inputs that broke templates for a short discussion in week 4.
