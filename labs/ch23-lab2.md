# Lab 23.2 — Steelman Check

| Field | Value |
|---|---|
| Type | Check It |
| Objectives | O3, O6 (LO5, LO3) · tags 4D:DISC, 4D:DIL |
| Time | About 30 minutes including reading this sheet and the debrief; optional |
| Materials | Printed, dated outputs (model name and date) from two tools for the prompt below (instructor package), or one run in a university-provided tool such as Microsoft Copilot Chat (as of October 2026); the source pack's one-page paraphrase sheet of Searle (1980) with section references; library access to Searle (1980) if available |

## Steps (tool-neutral)
1. **Get the output (5 min).** Prompt: "Give the strongest version of John Searle's Chinese Room argument and of the systems reply, with what Searle said in response." Use the printed outputs if you prefer not to run a tool. No personal data.
2. **Split (5 min).** Split the output into attributed claims, one per line ("Searle argued that …", "The systems reply says …", any quotation).
3. **Check (12 min).** For each claim, find the matching point on the paraphrase sheet and, where you can, in the article. Give a verdict on Chapter 8's scale: supported · partly supported · unsupported · contradicted · cannot verify. Treat any quotation as unsupported until you find it in the text.
4. **Record (3 min).** Count verdicts. Note any invented quotation or misattribution.

## Expected observations
Summaries of famous arguments are often broadly right and wrong in detail: a reply attributed to the wrong person, Searle said to claim that machines can never think (he did not), or a quotation that is not in the article. An invented quotation is a lead for your Failure Diary, not a tree label in this lab.

## If it does not work
If the library copy is not available, verdicts that depend on exact wording are "cannot verify"; say so.

## Debrief (3)
1. Which claim was hardest to verify, and why? (evaluate)
2. Did the output state Searle's view in a form he would accept? (evaluate)
3. Rewrite one wrong sentence so that it is supported. (create)

## Deliverable and rubric
A table: claim, verdict, where checked. Ungraded.

## Accessibility and alternatives
Printed outputs in plain text; the paraphrase sheet in an accessible format. No AI use is required.
