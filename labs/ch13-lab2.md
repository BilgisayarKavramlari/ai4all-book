# Lab 13.2 — Trace an Image

| Field | Value |
|---|---|
| Type | Check It |
| Objectives | O5 (LO5, LO3) · tags 4D:DISC, 4D:DIL |
| Time | 35 minutes (10-minute version: one item), at home; optional |
| Materials | Four provided, dated items with no people in them (buildings, landscapes, objects), each with a claim attached. Authentic, miscaptioned and edited items are built from **public-domain originals** that a reverse search can really find; a generated item comes with a **dated search-results sheet** (screenshots) instead of a live search, shows a fictional, non-local place, and stays on the course site only (never posted publicly). **Every** item carries the same neutral band outside the image, "COURSE SAMPLE — may be real or generated"; the real status of each item is only in the key, and content credentials (where present) carry the origin. A reverse image search tool; the check list (section 13.7); the answer key (opened only at step 3) |

## Steps (tool-neutral)
1. **Run the check list on each item (about 7 min each).** Some items are authentic as captioned; some are not. Source and channel → earliest version (reverse image search) → outside sources → provenance signals → content clues last. Note what each step found.
2. **Write a verdict** (Chapter 8's scale) and the remaining uncertainty for each item.
3. **Open the key (4 min).** For each item, note which step settled it.

**10-minute version:** one item.

In Compass (optional): reverse image search steps in several tools.

## Expected observations
The miscaptioned item is usually settled at step 2 (the public-domain original with a different place or date); the generated item at step 3 or 4 (the search-results sheet shows no earlier version and no outside trace, and its credential, if read, names an AI tool; "settled at step 3, no outside trace" counts); the edited item at step 2 (the unedited original). Content clues rarely settle an item alone.

## If it does not work
If a search finds nothing, record "no earlier version found": an absence, not evidence. Move to outside sources.

## Debrief (3–5)
1. Which step settled each item? (analyze)
2. Did any visual clue mislead you? (evaluate)
3. Which verdict was hardest, and what would you need to move it? (evaluate)
4. How would you write about the miscaptioned item if you had to mention it? (apply)

## Deliverable and rubric
A four-row record (item, findings per step, verdict, uncertainty, settling step). Ungraded.

## Accessibility and alternatives
Each item comes with a long description; a no-tool route uses the printed case packet (search results and outside reports already gathered).

## Safety and privacy
Provided items only; none shows an identifiable person or a real local disaster; all items stay on the course site with their neutral band, and generated items are never posted or shared as screenshots.

## Instructor notes
The four items and key are in the instructor package; have them ready before the session that uses this lab. Re-run every reverse search before term and update the dated search-results sheets. Keep the items different from the two items used in the optional verification protocol.
