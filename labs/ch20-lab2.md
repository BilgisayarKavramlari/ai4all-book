# Lab 20.2 — Read a Real Posting

| Field | Value |
|---|---|
| Type | Explore (optional, at home) |
| Objectives | O1 (LO7) · tag 4D:DIL |
| Time | 20 minutes |
| Materials | One public job posting or graduate program page in your field; your evidence map |
| AI tools | None needed |

## Steps (tool-neutral)

1. Choose one public job posting or graduate, medical or professional program page in your field. Use only what is public: do not log in, apply or upload anything.
2. List each thing it asks for (skills, experience, documents).
3. Next to each item, name the entry on your map that gives evidence of it, or write "no evidence yet."
4. Write one sentence on the gap you most want to close.

## Expected observations

Postings often list competencies as adjectives; the exercise is to translate each into a behavior you can show. Most students find at least one item with "no evidence yet"; that is a useful result.
