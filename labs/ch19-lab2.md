# Lab 19.2 — Read a Real Model Card

| Field | Value |
|---|---|
| Type | Check It (home, optional) |
| Objectives | O6 (LO6; LO5) · tags 4D:DISC, 4D:DIL |
| Time | 20 minutes |
| Materials | Links to two published model cards from two different providers (Compass and the companion files, dated); the model card's nine sections (section 19.7; Mitchell et al., 2019) |

## Steps (tool-neutral)
1. Open the two cards. Record the provider, the model and the date you read each card.
2. For each of the model card's nine sections, mark filled, partly filled or missing.
3. Write one "not for" line that one card should have had, and the evidence that would support it.

## Expected observations
Model details and intended use are usually filled; results by group and condition (the model card's factors and quantitative analyses) are often thin or missing, which is the gap Mitchell et al. (2019) argued about.

## Debrief
1. Which missing section would most change how you use the model? (evaluate)
2. Which section of your own workflow card is thinnest? (analyze)
