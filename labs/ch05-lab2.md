# Lab 5.2 — Same Task, Two Rungs

| Field | Value |
|---|---|
| Type | Compare |
| Objectives | O2 (LO2) · tags 4D:DEL, UNESCO:HCM-A |
| Time | 30 minutes, at home or in Compass (optional) |
| Materials | Any AI chat tool; a short course reading you have already read |

## Steps (tool-neutral)
1. Choose a short reading you have already read for a course (so you can check a summary against it quickly).
2. **Automation:** in a fresh, temporary chat, ask the tool to produce a summary. Check it against the reading and note how long checking took.
3. **Augmentation:** in another fresh chat, ask the tool to help you find the three main claims by asking you questions, without writing the summary. Write the summary yourself.
4. Compare in a three-row table: what you learned, how long checking took, which parts of the final summary were yours.

[COMPASS: ch05-lab2]

## Expected observations
Automation is faster to produce and slower to check; augmentation takes longer and leaves you able to explain the reading. Neither is better in general; the right rung depends on whether the skill is yours to build (Chapter 7).

## Debrief (3–5)
1. Which version could you defend in class without notes? (evaluate)
2. Where did the AI's ideas enter your own summary in the augmentation run? Could you still tell? (analyze)
3. For which of your courses would you choose each rung? (apply)

## Deliverable and rubric
Ungraded. The comparison table can support A3's rung reasons or A4 (Chapter 7).

## Accessibility and alternatives
No-device route: compare the dated sample AI summary on eLearning (model and date given) with your own summary of the same reading.

## Safety and privacy
Use course readings you are allowed to share with the tool; no personal data.
