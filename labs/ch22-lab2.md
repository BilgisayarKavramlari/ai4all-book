# Lab 22.2 — Trace an Energy Number

## The three figures (as of October 2026)
- 0.10 Wh per median text prompt, counting active AI chips only (Google, 2025; reported).
- 0.24 Wh per median text prompt, counting the full serving system (Google, 2025; reported; the blog says the figures were not verified by an independent third party).
- About 0.3 Wh per typical query to another provider's model (Epoch AI, 2025; outside estimate with stated assumptions).

## Steps (tool-neutral)
1. **Boundary table (12 min).** For each figure, mark which parts it counts: active chips; host computer and memory; idle capacity; cooling and building power; training; making the hardware.
2. **Explain (8 min).** In three sentences, explain why the figures differ. Use the words boundary, model and year.
3. **One more (5 min).** Find one energy or water claim about AI in the news. Can you fill its row? If not, which column is missing?

## Expected observations
No figure counts training or manufacturing; the two Google figures differ only by boundary; the Epoch estimate is for a different provider and rests on assumptions it states.

## If it does not work
If a source does not say what it counts, write "not stated": that is a finding.

## Debrief (3–5)
1. Which figure would you quote to answer "how much energy does my question use"? (evaluate)
2. Which figure would a grid planner need instead? (analyze)
3. What one disclosure would make news claims comparable? (create)

## Deliverable and rubric
The completed boundary table and three sentences. Ungraded.

## Accessibility and alternatives
Table available as plain text; no chart reading required.
