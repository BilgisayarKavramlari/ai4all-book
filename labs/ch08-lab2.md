# Lab 8.2 — Five References

| Field | Value |
|---|---|
| Type | Check It |
| Objectives | O3 (LO3) · tags 4D:DISC |
| Time | 30 minutes, home, optional, recommended |
| Materials | Any AI tool; your library catalog, a scholarly search engine, a DOI lookup or a publisher's site; the chapter's figure "A citation can fail in three ways, and each needs a different check" (section 8.3) |

## Steps (tool-neutral)
1. Ask an AI tool for five references on a narrow topic in your field (the concept-session demonstration, done yourself). Save the output with the tool's name and the date.
2. For each reference, run the three checks in order: (a) does it exist in an index no AI tool produced (stage 1); (b) does every detail match the record (authors, year, title, venue, pages; stage 1); (c) open it and find the passage that supports the claim, if the output made one (stage 2).
3. Give each a verdict (supported, partly supported, unsupported, contradicted, cannot verify) and an uncertainty line naming the indexes you searched. Not found in two indexes = unsupported, not "fabricated"; a record showing another work = contradicted as cited.
4. Keep the record: Chapter 9's source audit (A6) builds on it.

"All five were real and said what was claimed" is a valid result.

[COMPASS: ch08-lab2 — current free indexes and DOI lookup]

## Expected observations
Results vary by tool, topic and whether the tool searched the web. Niche topics and older literature produce more failures of types 1 and 2; tools that retrieve sources produce more failures of type 3 (real source, unsupported claim).

## Debrief
1. Which failure type did you find most often? (analyze)
2. For a reference you could not find, why is "unsupported" more accurate than "fabricated"? (explain)

## Deliverable and rubric
Ungraded. The five-row record; reusable as A5 citation rows and in A6.

## Accessibility and alternatives
No-device route: the five dated sample references on your course site. Library staff can help at the reference desk; tell them the references came from an AI tool.

## Instructor notes
Remind students not to submit unchecked AI references in any assignment; this lab is the safe place to find them.
