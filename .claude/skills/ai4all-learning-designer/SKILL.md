# AI for All — learning designer

Run this BEFORE any chapter is drafted. No chapter text is written until the author approves the blueprint.

## Inputs
- docs/syllabus.md (the week, its studio artifact, LO1–LO7)
- docs/book-map.md, docs/chapter-anatomy.md
- reference/learning-science.md (in this skill folder)
- The ai4all-frameworks skill for framework tags
- Blueprints of the two previous chapters (docs/blueprints/) for spacing and prerequisites

## Steps
1. **Outcome link.** Name the syllabus learning outcome(s) this chapter serves (LO1–LO7) and the studio artifact of that week.
2. **Chapter objectives.** Write 4–6 objectives. Each: one measurable Bloom verb (revised taxonomy), the LO code, at most 3 framework tags. No "understand" or "know" as verbs.
3. **Prerequisites.** List what the reader must already know, and which earlier chapter taught it. Flag anything not yet taught.
4. **Misconceptions.** List 3–5 likely misconceptions of a non-CS undergraduate about this topic, and where in the chapter each is confronted.
5. **Concept sequence.** Order the ideas concrete → abstract. Split into 5–8 subsections, each introducing at most one new core idea (cognitive load).
6. **Example plan.** For each key skill: one worked example, one faded example, one "Your Turn". Rotate fields: at least 3 different majors per chapter (business, health, arts and humanities, social science, natural science, engineering).
7. **Retrieval and spacing.** One "Check Yourself" per subsection; 3–5 Spaced Review items drawn from the two previous chapters.
8. **Alignment matrix.** Table: objective × (subsection, figure, lab, end-of-chapter item, studio artifact). Every objective needs at least one practice opportunity and one assessment item. Every assessment item maps to an objective.
9. **Figures.** List the planned figures (title states the finding) and mark which one is a signature diagram.
10. **Workload.** Estimate reading time (Core path) and lab time. Target: Core reading ≤ 60–75 minutes per week, consistent with the syllabus workload.
11. **Risks.** Note sensitive content (bias, legal cases, named organizations) that needs extra fact-checking.

## Output
Save docs/blueprints/chNN-blueprint.md with the sections above, then give the author (in Turkish) a 5-line summary and the open decisions.
