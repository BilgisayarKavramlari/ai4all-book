# Learning science reference for AI for All

Use these principles when planning and drafting. Cite the original source if the book itself discusses the principle.

| Principle | What it means for this book | Source |
|---|---|---|
| Backward design | Start from outcomes and assessment, then choose content | Wiggins & McTighe, *Understanding by Design*, 2005 |
| Revised Bloom's taxonomy | Objectives use measurable verbs: remember, understand, apply, analyze, evaluate, create | Anderson & Krathwohl, 2001 |
| Retrieval practice | Short low-stakes recall questions after each subsection ("Check Yourself") | Roediger & Karpicke, 2006; Dunlosky et al., 2013 |
| Spaced practice | Revisit earlier chapters in Spaced Review | Dunlosky et al., 2013 |
| Worked-example effect | Novices learn faster from worked examples, then faded examples | Sweller & Cooper, 1985; Renkl, 2014 |
| Cognitive load | One new core idea per subsection; remove decorative detail | Sweller, 1988 |
| Multimedia principles | Coherence, signaling, redundancy, spatial and temporal contiguity, segmenting, pre-training, personalization | Mayer, *Multimedia Learning*, 3rd ed., 2020 |
| Desirable difficulties | Interleaving and generation tasks improve retention even when they feel harder | Bjork & Bjork, 2011 |
| Elaborative interrogation | "Why does this happen?" prompts | Dunlosky et al., 2013 |
| Universal Design for Learning | Multiple means of engagement, representation, action and expression | CAST, UDL Guidelines 3.0, 2024 |
| AI tutoring guardrails | AI help that gives answers can raise practice scores but lower later unaided performance; hint-only tutoring avoids this | Bastani et al., PNAS, 2025 |

Rules of thumb:
- Concrete case first, then the concept, then the general rule, then a non-example.
- Every figure must earn its place: it shows a mechanism, comparison, or process that text alone cannot.
- Questions that ask students to judge or decide (evaluate) matter more in this course than recall.
