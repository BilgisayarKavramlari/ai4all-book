# Author voice

Put 5–10 samples of your own English writing in docs/voice/samples/ (articles, blog posts, lecture notes, long emails; .md, .txt or .docx). More variety is better than more length.

Then ask Claude Code: "ai4all-author-voice ile ses profilimi oluştur." It writes docs/voice/voice-profile.md and asks you to confirm a few points.

Field stories for "From the Field" sections go in docs/field-notes/ as short notes (what happened, when, what you learned). Claude never invents these.
