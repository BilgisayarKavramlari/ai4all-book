## How page ranges were judged

- **TOC** = the contents page of the issue on the website, or the contents page inside the issue PDF when the website lists no pages (Dec 2014).
- **Folios** = the page numbers printed on the pages of the issue PDF, where the article's text actually starts and ends.
- The journal's TOC prints each article's range as start page to the *next article's start page*. The TOC end is therefore often one page too long: for example Elaboration Likelihood Model is 15-17 in the TOC but its text ends on printed p. 16, and Actor Network Theory starts on 17. In one case (Social CRM) the TOC ends on p. 41 but the issue PDF ends on p. 40.
- A chapter range that equals the TOC **or** the folio span is marked *confirmed*. A range that equals neither is *corrected*, to the folio span when the TOC start page agrees with it, because the folio span is what the article itself occupies. Where the TOC end differs, the table says so. **Author decision:** if the book prefers the TOC's printed ranges everywhere, five endings change (rows 4, 9, 14, 16, 21 would become 2-5, 15-17, 21-26, 17-20, 26-28; rows 10 and 23 would become 37-41 and 17-19).
- Each entry's own "recommended citation" line was often copied from another entry (see notes) and was not used as evidence.
