# Style sheet

To be completed from the design guide by prompts/01-bootstrap-context.md. Starting rules:

- American English; address the reader as "you"; author asides in "I".
- Average sentence under 20 words; paragraphs of at most 4 sentences.
- No anthropomorphic verbs for AI systems.
- Every factual claim: source + year; APA 7 references.
- Define each acronym at first use in every chapter.
- Main text is tool-neutral; tool click paths belong in Compass.
- Accessibility: WCAG 2.1 AA, meaningful alt text, no color-only meaning, math in LaTeX/MathML.
- Reading paths: Core / Studio / Deep.
