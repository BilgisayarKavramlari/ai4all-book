# Visual guide

Diagrams carry the text; they are not decoration. Target: 15–25 figures per chapter (about 400–500 in the book), built around 12 signature diagrams. A signature diagram is built in the chapter where it first appears and reused later with the same drawing, highlighting only the relevant part. Readers learn the visual language once.

## Visual grammar (fixed for the whole book)

| Rule | Application |
|---|---|
| Color carries meaning, never alone | Fixed palette for four roles: human action, AI action, risk or warning, verified information. Colorblind-safe. Every color meaning is repeated by shape, line style or label. |
| Shape grammar | Rectangle = step · diamond = decision · rounded box = human · hexagon = AI component · dashed outline = uncertainty |
| Density limit | At most 9 boxes per diagram; split anything larger into two diagrams |
| The title states the finding | Not "Verification funnel" but "Most claims fail before they reach a primary source" |
| Short captions | Under 25 words; explanation belongs in the text |
| Figure identity | "Fig. 8.3" in the book = the same code for the interactive version in Compass; QR / short link |
| Accessibility | Alt text under 150 characters on every figure; long description for complex figures (figures/longdesc/); text contrast at least 4.5:1 |
| Generative images | Never in diagrams or data charts; if used for a scene illustration, labeled in the caption |

## Two renders of every figure

The print interior (Draft2Digital Print) is grayscale; the EPUB 3 is color. Every figure is produced twice, in figures/out/color/ and figures/out/gray/. Meaning must survive the grayscale render: rely on shape, line style (solid, dashed, dotted), fill pattern and labels, never on hue alone. Check each gray render before a figure is marked done.

## Production pipeline

1. **Sketch.** The author sketches each subsection's diagram before the text (paper or Excalidraw); the text is written around it.
2. **Source file.** Simple flows in Mermaid; complex drawings in SVG or draw.io; all sources in Git under the book's license.
3. **Data charts.** Generated by code (reproducible) from data/*.csv; never typed by hand.
4. **Professional drawing.** Signature diagrams and chapter maps finished by a freelance illustrator in one style (docs/decisions.md D8); all other figures are produced in-house from source files.
5. **Accessibility check.** Alt text, contrast, colorblindness simulation, grayscale check.
6. **Interactive version.** Step-by-step versions of signature diagrams in Compass; also used as lecture slides.

Register every figure in figures/index.csv (id, chapter, title, type, source, status).
