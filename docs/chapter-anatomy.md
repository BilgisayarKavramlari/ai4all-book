# Chapter anatomy

Every chapter follows the same 14 parts in the same order. Readers learn the pattern once and can find anything in any chapter. Source: the book design guide (October 16, 2026), proposals the author has accepted in outline; details may still change.

## The 14 parts

| # | Part | What it contains | Size or count |
|---|---|---|---|
| 1 | Chapter Map | One-page visual map of the chapter: concepts, labs, case, assignment; a "this chapter in 20 minutes" summary; the AI Work Loop with this chapter's step highlighted | 1 page |
| 2 | Opening Case | A real, cited event that frames the chapter's problem; the chapter returns to it at the end | 300–600 words |
| 3 | Learning Objectives | Revised Bloom verb + syllabus outcome code (LO1–LO7) + framework tag (UNESCO, AILit, AI Fluency 4D) | 4–6 objectives |
| 4 | Warm-up | Ungraded pre-test; automated in Compass | 3 questions |
| 5 | Core Text | Subsections, each tagged Core, Studio or Deep; at least one figure per subsection; each ends with Check Yourself | 5–8 subsections of 1,500–2,500 words; Check Yourself 2–3 questions each |
| 6 | Worked Example → Faded Example → Your Turn | For each skill: a fully solved example, a partly solved one, then free practice | 1 sequence per skill |
| 7 | Hands-on Labs | Tool-neutral task description in the book; step-by-step tool instructions, data files and feedback live in Compass | 2–4 labs |
| 8 | Case Study | Cited real-world case using cases/TEMPLATE.md | 1 main + 1–2 short |
| 9 | Ethics Lens | The responsibility dimension of the chapter's topic | 1 box or short section |
| 10 | Career Connection | How the topic is used in at least three occupations | ≥ 3 occupations |
| 11 | From the Field | Anonymized case from the author's industry and SME work; only the author supplies these — never invent one | 1 |
| 12 | Chapter Summary + Key Terms | Visual summary card; every key term goes into docs/glossary.md | 1 card |
| 13 | End-of-Chapter Package | See the table below | — |
| 14 | Further Reading & Compass Links | Selected readings with full APA 7 references; QR codes / short links to Compass | 5–10 items |

Volume target: at least 10,000 words per chapter; 15–25 figures per chapter.

## End-of-chapter package

The review questions mirror the three-part exam (terms and concepts, case, interpretive), so every chapter gives exam-format practice.

| Component | Count per chapter | Format | Link to exam and syllabus | Compass counterpart |
|---|---|---|---|---|
| Review Questions A — Terms & Concepts | 10–15 | Multiple choice, matching, short definition | Exam section A | Auto-graded quiz with explained feedback |
| Review Questions B — Case Questions | 3–5 | Short case + justified decision | Exam section B | Rubric-scored answer, model answer |
| Review Questions C — Interpretive Questions | 2–3 | Take a position and defend it | Exam section C | Sample strong and weak answers |
| Spaced Review | 3–5 | Questions from the two previous chapters | Spaced practice | Personal review queue |
| Discussion Questions | 4–6 | Open-ended; at least one ethics, one career, one interdisciplinary | Studio and group work | Moderated discussion board (optional) |
| Application Assignment | 1 main + 1 alternative | The syllabus's weekly studio artifact, with submission criteria, rubric and AI Use Declaration | Weekly portfolio artifacts (20%) | Template, sample submission, self-check |
| Hands-on Labs | 2–4 | Step-by-step practice with checkpoints | In-class lab | Interactive lab, progress tracking |
| Case Study Questions | 4–6 | Analysis questions specific to the case | Preparation for case questions | Case file with source links |
| Mini-Project (optional) | 1 | Multi-week; feeds the term portfolio | Final portfolio | Project space |

Every item carries an LO code and a Bloom level.

## Answers and instructor material

| Material | Where it lives | Why |
|---|---|---|
| Answers to odd-numbered Review Questions | Appendix E of the book and Compass | Corrective feedback |
| Even-numbered answers, test bank, certification item bank | private/ only (never committed, never in the public book) | Assessment security |
| Rubrics (assignments, portfolio, oral defense) | Open, in the book and Compass | Expectations visible in advance |
| Slides, instructor notes, sample syllabus, figure sources | Instructor package | Adoption by other instructors |

## Reading-path tags

| Tag | Meaning |
|---|---|
| Core | Required weekly reading; examinable |
| Studio | Hands-on material used in the Thursday lab |
| Deep | Optional extension; not examinable |
